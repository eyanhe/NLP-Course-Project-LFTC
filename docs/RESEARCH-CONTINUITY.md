# 从交接前的模型比较，推进到能力边界与失败机制

整个项目可以写成一项逐步深入的研究：**先比较不同模型在哪些任务和分布条件下表现不同，再追问这些差异由什么条件形成、为什么会失败。** 交接前的实验提供现象和问题起点，当前v3用规模、优化和机制对照继续解释。

## 1. 交接前已经回答了什么

2026-11-06交接的核心问题是：传统特征与线性模型何时已经足够，预训练Transformer何时有更大优势，训练类别不平衡怎样改变模型表现？原项目已做四套常规单文本分类、MultiNLI句对分类和AG News不平衡/加权实验，也报告了性能、逐类错误和CPU推理成本。[原交接说明](../HANDOFF.md)、[原中文结论](../report/final-synthesis-zh.md)、[原英文报告](../report/final-report.md)。

原项目得到的不是一个简单的模型总排名：

- **模型差距依赖任务。** IMDb、Yelp中TF-IDF+LR与DistilBERT的Macro-F1差距约0.54、0.90个百分点；RT和AG News约4.99、3.96个百分点。BiLSTM也没有自动超过稀疏模型。
- **复杂句对任务上的优势更大。** MultiNLI matched的配对SVM与DistilBERT分别为0.4990、0.6580；mismatched分别为0.5111、0.6721。神经分数为三个训练种子均值，评估来自官方validation池的保留样本。
- **分布变化改变失败程度。** AG News严重倾斜时，SVM的Macro-F1下降77.76点，DistilBERT下降12.86点；加权后SVM从0.1000恢复到0.4000，仍未恢复均衡基线。
- **平均性能之外还有成本和具体错误。** 原项目已有CPU batch=1延迟、hypothesis-only诊断与待复核错误队列；这些提示应继续研究模型使用了什么线索、哪些样本失败，而非只看总体分数。

这些是交接时已存在的实测结果，不能计作接手后的新实验。下面的“继续追问”是当前对原发现的研究性梳理，不意味着所有后续假设当时已经提出。

## 2. 这些发现怎样引出当前实验

| 交接前的发现或未解问题 | 顺着它继续追问 | 当前实验如何接续 | 当前得到的推进 |
| --- | --- | --- | --- |
| 常规任务差距有大有小，BiLSTM并非总优于传统方法 | 差距随数据量怎样变化？低分是否来自优化不足？ | E1规模对照、S1学习率×预算、后续早停网格与固定模型Q | 部分早期低分受配方影响；两组优化Q均为DistilBERT>SVM>BiLSTM，能力具有条件性 |
| MultiNLI上预训练Transformer优势明显，但外部预训练与架构差异并存 | 预训练初始化和下游适配各贡献什么？ | M2在BANKING77固定架构，做初始化×冻结/解冻四臂匹配 | V证据支持预训练与任务适配共同起作用；这回答同类归因问题，不直接解释原MultiNLI分差 |
| AG News长尾退化严重，加权只能部分恢复；原报告未分离样本稀缺与先验/目标变化 | “独立标注不足”和“训练贡献不足”能否分开？加权能否替代数据？ | E3扩展任务观察，S3固定表示下分离支持×贡献并评估Q | 本组均匀贡献无法补回删减的尾类独立标注；整体改善可以伴随尾类继续失败 |
| 已有样本级预测、错误候选及hypothesis-only线索，但原因尚未系统验证 | 增加数据修好了谁？线索形式改变会不会触发错误？ | S2同样本1k→6k轨迹；S4配对词汇替换与同预算控制 | 定位纠正、持续和新增错误；37对AI审核子集中SVM对线索替换更敏感，两个模型也存在共同失败 |
| 传统模型较低延迟与神经模型的性能优势需要权衡 | 在当前研究条件下，这些结果各付出多少训练和预测成本？ | 分开记录后续优化轮的训练流程、加载与批预测时间 | 延续性能—成本分析，但旧batch=1延迟与当前批预测均摊时间按各自条件报告 |

**新增GoEmotions、BANKING77和Yahoo的作用**是扩展情绪多标签、细粒度意图和不同主题文体的数据条件；它们服务于问题推进，不单凭“多了三个数据集”构成机制解释。受控证据主要来自同一语料内的比较。

## 3. 整个研究应怎样讲

可以直接用以下表述作为报告的研究动机与阶段衔接：

> 项目首先在常规文本分类、句对语义分类及受控类别不平衡条件下比较传统方法与深度模型。结果表明，模型优势随任务与分布条件变化，预训练Transformer并非在所有条件下都以相同幅度领先，传统模型也具有计算成本优势。这些比较进一步引出了两个问题：不同模型的优势在什么数据条件下成立，以及性能下降由哪些因素造成。为此，后续研究扩展数据条件，并通过规模对照、优化敏感性分析、预训练与适配消融、标注支持与类别贡献分离、错误轨迹和词汇干预，将性能比较推进到能力边界与失败机制的解释。

研究链为：

**交接前的任务/分布/成本比较 → 发现条件性优势和局部失败 → 提出规模、优化、表征与监督信息假设 → 当前匹配对照和干预 → 独立Q验证及定量/定性解释。**

这条线保留三个层次：交接前结果描述表现；当前跨数据集比较扩展现象；同数据内的对照/干预为对应因素提供更直接的局部解释。

## 4. 连续叙事中的证据口径

- 原MultiNLI作为复杂句对任务的既有证据保留。本轮没有重做其主实验，BANKING77机制结果不能冒充对MultiNLI内部机制的验证。
- 原报告的测试条件与v3的V/D/Q划分、数据样本、输入窗口和配方不同；同名数据集也不直接拼接为一条学习曲线或新旧模型提升量。
- 原延迟为四CPU线程、batch=1的评论工作负载；本轮计时为集群CPU八线程及批预测均摊，不能把两者相除称为加速比。
- 原错误队列未因此完成真人复核。当前S4按Gemini辅助审核的37对干预子研究报告，不是对原全部错误类型的统一验证。
- 当前232条研究训练记录、42个Q模型是v3范围；原交接模型与结果另列，接续关系不意味着混合数量。
