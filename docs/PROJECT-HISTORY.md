## 接手后的主要工作

研究的逻辑接续为：**原任务/分布/成本比较发现条件性优势 → 追问数据量、优化、表征与监督信息的作用 → 当前对照和干预提供局部机制解释。** 原成果是当前问题的实证起点；后续工作从扩大比较推进到分解原因。[完整的接续说明](RESEARCH-CONTINUITY.md)逐项对应原发现、新问题和当前证据。

## 统一计数

`184 + 16 + 8 + 24 = 232`，是当前研究的独立完成模型记录，其中226有V指标、42有Q。184中6个按strict_no_val设计没有V。

早期217个候选中36个已复用进184，所以额外候选为181。全部v3完成记录为`232 + 181 + 15 = 428`。2个中断记录另存。续跑和复用按run_id只计一次。

184个首批模型的预算为BiLSTM10轮、DistilBERT/ModernBERT5轮、M2机制10轮；传统模型按求解器拟合。完成记录表示跑完既定预算并保存/重载，不能一律称为充分优化且独立测试完成。另15个E0才是单独的工程小样本。

原始主设计2,859项只完成184项；后续48项新增训练独立登记。当前数据可以支持已测条件下的结论，尚未完成整个大矩阵或全部机制。
