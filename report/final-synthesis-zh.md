# 文本分类项目：最终实验主线与结论

本项目比较五种模型，并通过常规文本分类、复杂句对推理和训练类别不平衡三个实验回答不同问题。以下结论来自真实运行结果，不把预期结论当作实验结果。

## 1. 常规任务：准确性与推理成本的取舍

IMDb 和 Yelp 上，TF-IDF + LR 与 DistilBERT 的 Macro-F1 相差不到 1 个百分点；Rotten Tomatoes 和 AG News 的差距更明显。因此建议写为“部分常规任务性能接近，差距依赖数据集”，而不是“所有简单任务都一样”。同一批评论输入、四个 CPU 线程和 batch=1 的已有测试显示传统模型推理更快。新闻检查点的该延迟测试仍使用评论输入，不能直接当成新闻生产流量的延迟。

- imdb: TF-IDF + LR 0.8880，DistilBERT 0.8933，差距 0.54 个百分点。
- rotten_tomatoes: TF-IDF + LR 0.7880，DistilBERT 0.8379，差距 4.99 个百分点。
- yelp: TF-IDF + LR 0.9340，DistilBERT 0.9430，差距 0.90 个百分点。
- ag_news: TF-IDF + LR 0.8800，DistilBERT 0.9195，差距 3.96 个百分点。

## 2. MultiNLI：复杂语义任务中的 Transformer 优势

在 6,000 个训练句对的预算下，DistilBERT 在 matched/mismatched 两个保留评估集上的 Macro-F1 均高于所测传统基线和 BiLSTM；预先指定的 seed42 对 SVM 比较区间也均为正。这里支持“预训练 Transformer 在此复杂任务和预算下更好”，不支持把所有深度学习都视为同样有效。该任务评估使用官方 validation 子集，不是隐藏测试榜单；预训练资源也不同。

- mnli_matched: 配对 TF-IDF + SVM 0.4990，DistilBERT 0.6580。
- mnli_mismatched: 配对 TF-IDF + SVM 0.5111，DistilBERT 0.6721。

## 3. 类别不平衡：比较各模型自身的衰退

训练总量固定为 6,000，从每类 1,500 条逐步变为 World 5,640 条、其他每类 120 条；验证和测试始终每类 250 条。主要看 Macro-F1 和三个少数类的平均 Recall，并相对各自均衡基线计算下降百分点。

- TF-IDF + LR：严重不平衡 Macro-F1 0.1082，下降 77.17 个百分点；少数类 Recall 0.0053，下降 87.47 个百分点。
- TF-IDF + SVM：严重不平衡 Macro-F1 0.1000，下降 77.76 个百分点；少数类 Recall 0.0000，下降 88.00 个百分点。
- Word2Vec + SVM：严重不平衡 Macro-F1 0.2856，下降 56.41 个百分点；少数类 Recall 0.1373，下降 70.80 个百分点。
- Word2Vec + BiLSTM：严重不平衡 Macro-F1 0.4424，下降 42.54 个百分点；少数类 Recall 0.2991，下降 57.60 个百分点。
- DistilBERT：严重不平衡 Macro-F1 0.7910，下降 12.86 个百分点；少数类 Recall 0.7200，下降 20.40 个百分点。

类别加权补救实验：

- DistilBERT：Macro-F1 变化 +2.83 个百分点，少数类 Recall 变化 +4.84 个百分点。
- TF-IDF + SVM：Macro-F1 变化 +30.00 个百分点，少数类 Recall 变化 +24.13 个百分点。

本次下降最多的是 TF-IDF + SVM，而严重条件下绝对Macro-F1最高的是 DistilBERT。少数类样本变少会影响特征和分类边界的学习，先验改变也会鼓励多数类预测；本实验没有把这些机制逐一分离，也不能把预训练资源差异完全归于网络架构。

因此最终结论应把绝对能力、推理成本和分布变化下的鲁棒性分别讨论。少数类召回率下降不能被总体准确率掩盖，也不能由单次实验概括为某一大类方法永远更稳健。

为说明准确率的局限，另提供标签先验变化的加权模拟：94% World 的部署分布下，只预测 World 就能得到 94% 模拟准确率，但均衡测试的 Macro-F1 只有 0.10，少数类 Recall 为 0。该 94% 是数学示例，不是模型实测结果。
