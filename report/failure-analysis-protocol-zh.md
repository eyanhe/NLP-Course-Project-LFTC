# 文本分类失败分析协议与已有案例起点

历史讨论与案例起点。当前正式失败审计、干预及统计规则见[完整研究设计](../docs/superpowers/specs/2026-11-07-text-classification-research-design.md)第7—9节。

日期：2026-11-07。状态：研究设计与已保存记录的检查；没有新增模型推理、人工双人复核或因果验证结果。

## 1. 当前材料与缺口

当前检查发现：`results/error_review.csv`有60条情感错误候选，`results-hard/error_review.csv`有24条MultiNLI候选，状态均为`unreviewed`。`error-analysis-assistant-draft.md`提供12个情感案例的助手分析，明确标注未经真实成员复核。

情感队列按金标类别从至少一个原始主模型预测错误的候选中抽取，列出的模型是LR、SVM和DistilBERT seed42。它不是对所有样本的简单随机抽样；分析不能直接推广为总体失败原因占比。新增Word2Vec、BiLSTM和不平衡实验虽保存逐样本预测，仍需统一的样本级失败分析流程。

现有材料提供了案例起点。还需明确失败分类、对照样本、模型可见输入、机制验证及未解决问题，并把这些证据与规模和分布实验连接。

## 2. 研究单元与记录字段

基本单元为“样本 × 模型 × 训练/推理条件”。使用稳定的样本标识跨条件连接。

| 字段组 | 必须记录的内容 |
| --- | --- |
| 数据与任务 | 样本标识、原文/句对、来源、任务、原始金标及标签定义 |
| 运行条件 | 模型与权重标识、抽样和训练种子、训练规模、每类/标签支持数、类别分布及阈值 |
| 观察事实 | 预测标签/标签集合、可用的分数及分数类型、实际输入片段、截断和未知词情况 |
| 标签核实 | 金标是否合理、是否存在歧义或信息不足、核实依据、真实复核人和分歧状态 |
| 失败现象 | 一至多个现象标签；为每个现象记录文本证据位置 |
| 原因假设 | 可检验的机制、替代解释、预期支持与否定结果 |
| 验证记录 | 原样本和改写/干预样本、必要的正确对照、干预有效性检查、预测前后结果 |
| 结论 | 观察成立、机制待检验、得到有限支持、被否定或仍未解决；适用范围 |

SVM margin与未校准概率分别记录，不能把数值大小直接当作跨模型可比置信度。多标签任务须分别标记漏检、误报及标签组合错误。

## 3. 失败现象分类的起始版本

这些是待通过发现样本修订的分析标签，不能未经审阅就自动赋给全部错误。

| 范围 | 候选现象 |
| --- | --- |
| 情感 | 否定范围；转折与最终立场；混合评价；题材内容与评价态度混淆；隐含贬义/反讽；评价对象识别错误 |
| 情绪 | 相近情绪或强度混淆；隐含情绪；少数标签漏检；共现标签压制；叙述事件与表达情绪混淆 |
| 主题 | 实体/关键词诱导；多个话题并存；细分类边界；标题与正文信息不一致；仅依据表面词汇 |
| 意图 | 同主题不同操作；状态询问与操作请求混淆；否定和条件限制；关键对象或动作识别错误；信息不足 |
| 句对语义 | 互斥状态未识别；否定、数量或角色关系混淆；词汇重叠诱导；缺失信息与矛盾混淆 |
| 通用输入与数据 | 关键证据在输入窗口外；清理/编码异常；未知词或零向量；标注冲突；现有标签体系无法表达输入 |

“文本有转折”描述语言现象；“模型只依赖正面词”是假设机制。二者分别标注。输入被截断是可核实事实，但仅凭这一事实仍不能确定截断导致了该次错误。

## 5. 从案例到机制的验证流程

1. 核对原文、金标、记录和模型版本，确认是否属于明确预测失败；保留标注歧义和任务不可判定情况。
2. 提取模型真正看到的输入，并检查预处理、截断、词表覆盖和分数计算。先排除实现或输入问题。
3. 标注语言现象，提出候选机制及至少一个有现实可能的替代解释；未知原因允许保持未知。
4. 设计最小且可核实的对照。明确修改是否应保持标签，或是否应使标签改变；记录预期响应。
5. 在同一固定模型上做配对诊断；涉及训练机制时，使用预先固定的受控重训，所有额外监督和计算单列。
6. 在独立样本上复现该失败模式及干预效应，检查正例、反例和正确对照，限制结论适用范围。

线性模型的特征贡献可解释当前线性分数如何形成；它仍不能独自证明一种语言理解缺陷的普遍原因。词级归因或注意力图作为诊断线索记录，并通过行为对照补充。

## 6. 抽样、比例与重复性

保留两个用途不同的集合：

- 发现与深入诊断集合：覆盖模型分歧、全部失败、少数类、极短/长文本及不同任务；允许有目的抽样，明确不能直接估计总体发生率。
- 独立审计集合：按固定协议随机或分层抽样，记录纳入概率与权重，同时包含正确和错误样本，用于估计失败模式的覆盖、条件错误率和不确定性。

对同一现象同时报告“该现象的样本中有多少错误”和“错误中有多少包含该现象”，说明分母。仅审查错误无法知道某现象是否同样大量存在于正确样本中。现象标签可重叠，不要求各类比例相加为100%。

复核者先按固定指南独立标注，记录分歧；只有真实完成后填写复核身份与状态。若使用助手预标注，应单独标明，避免将其当作独立人工共识。

## 7. 与规模和分布实验连接

固定审计样本，跨模型、规模、分布和种子追踪：

- 持续错误：增加数据或更换条件后仍然失败。
- 得到纠正：原来错误，在新条件下正确。
- 新增错误：原来正确，在新条件下失败。
- 不稳定错误：随数据抽样或训练种子切换结果。

进一步比较这些变化由哪些现象组成，以及对应干预的效果是否也发生变化。例如，更多数据是否纠正近邻意图混淆，却没有改善否定范围；类别加权是否减少尾部漏检，却增加同组标签误报。以上是待研究的问题，不是本项目已有结果。

最终报告为每种主要失败模式提供可追踪的原样本、模型分歧、证据、对照、未解决问题，以及该模式随训练条件变化的情况。总体指标用于判断其影响范围，具体失败用于解释影响如何发生。
